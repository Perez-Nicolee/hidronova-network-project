# 🌐 Proyecto Integrador de Redes — HidroNova S.A.

Proyecto académico realizado en **Cisco Packet Tracer** para la materia **Redes de Computadoras** de la Licenciatura en Informática de la Universidad Nacional de Quilmes (UNQ).

> 📌 HidroNova S.A. se utiliza como caso académico de simulación.

## 📋 Proyecto

Diseño y simulación de una red empresarial multisede que conecta **CABA, San Salvador de Jujuy y Catamarca**.

Durante el desarrollo se trabajó con conceptos como:

- TCP/IP e IPv4
- Subnetting y VLSM
- VLANs y trunks 802.1Q
- Router-on-a-Stick
- Routing estático
- DHCP y DHCP Relay
- DNS
- NAT/PAT
- HTTP / HTTPS
- SMTP / POP3
- Ethernet, Gigabit Ethernet y fibra óptica
- Wi-Fi con WPA2-PSK / AES
- Análisis de tráfico con sniffers
